=========================
GAME DATA LOGIC
=========================

Connect the gacha UI to Supabase.

When user presses:

"Wish x1"

or

"Wish x10"


Perform:

1. Check player crystal balance.
2. Deduct crystals:
   - x1 = 160 crystals
   - x10 = 1600 crystals

3. Update pity counter.

4. Generate rewards according to rates:

★★★★★ 1%

★★★★ 8%

★★★ 91%


Pity system:

- Soft pity starts at 74 wishes.
- Hard pity guarantees ★5 at 90 wishes.
- Featured character guarantee after losing 50/50.

After pull:

- Save obtained card to collections table.
- Update player resources.
- Update pity progress.
- Show reward animation.

=========================
SUPABASE IMPLEMENTATION
=========================

Create:

src/lib/supabase.ts

Initialize Supabase client using environment variables:

VITE_SUPABASE_URL

VITE_SUPABASE_ANON_KEY


Create reusable hooks:

useAuth()

Handles:
- login
- signup
- logout
- session state


usePlayerData()

Handles:
- loading player profile
- saving resources
- updating pity
- saving obtained cards


Use async/await and proper loading/error states.


=========================
SECURITY
=========================

Enable Row Level Security.

Users can only:

- read their own profile
- update their own resources
- update their own pity
- access their own collection


Do not expose service role keys.

Use only public anon key on frontend.
